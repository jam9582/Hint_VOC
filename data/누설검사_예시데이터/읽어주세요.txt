누설 검사 판정 편차 — 수업용 가상 데이터
기준 문서: PRD_VOC통합관리_v2.docx 6~8장. 시각은 한국 시간.
문서에 정의된 업무용 표 6종: voc, voc_8d, voc_stage_log, vehicle, vehicle_part, code.
추가 파일: data_dictionary(업무용 타입/입력 규칙), type_detail_fields(유형별 폼), leak_test_measurement(측정 보조 표), measurement_dictionary(측정 보조 표 명세).
모든 차대번호·일시·협력사·LOT·검사 수치·봉쇄 조치는 가상 예시이며 실제 시험 결과가 아닙니다.
실제 누설이 확정되지 않아 ETC로 분류했습니다. 냉매/질소 누설은 기존 LEAK 선택지와도 정확히 맞지 않으므로 임의 코드 추가 없이 ETC를 사용합니다. type_detail은 공통 선택값 repair_history만 포함합니다.
기준 문서에는 온도/압력 전용 열이 없어 측정값은 업무용 표에 열을 추가하지 않고 보조 표로 제공합니다.
VOC 3건: 11월 4~5일 접수 2건은 가상 봉쇄 완료 후 D4, 11월 6일 1건은 D3. 근본 원인·재현 검증·영구 대책·효과 검증·종결은 미완료이며 해당 칸은 공란입니다.
재검 OK는 실제 누설 없음 또는 출하 가능의 확정을 뜻하지 않습니다. 온도와 판정의 연관성을 표현한 가상 수치이며 원인 검증을 대신하지 않습니다.
가상 시험 조건: 질소, 설정 게이지압 500 kPa, 유지 30초, 압력강하가 1.0 kPa 초과이면 NG. 실제 시험 규격 또는 권장 기준이 아닙니다.
각 VOC는 동일 LOT 장착 차량을 대표합니다. 각 sample_id는 그 차량 배관의 검사 포인트/반복 조건 표본이며 별도 차량 수를 의미하지 않습니다.
similar_ids는 해당 접수 시점에 존재하는 이전 VOC만 최근 순으로 연결했습니다. 기한은 문서 예시대로 D3 접수+2일, D4 접수+7일입니다.
CSV는 UTF-8 BOM. 빈칸=미입력; 0 또는 없음과 구분합니다. CSV는 타입/입력 방식/자동 생성을 강제하지 않으며 명세를 앱의 가져오기 설정에 적용해야 합니다.
Excel: 데이터 → 텍스트/CSV에서 가져오기. ID/VIN/부품번호/LOT/코드/JSON은 텍스트, 주행거리/연식/순서/기록번호는 정수, 측정 온도/압력은 소수, 일시는 YYYY-MM-DD HH:MM, 날짜는 YYYY-MM-DD로 해석합니다.
자동 항목은 예시 상태를 재현하기 위해 미리 채웠습니다. 실제 앱 신규 등록에서는 사용자가 입력하지 않고 앱이 생성합니다. active는 예/아니오이며 boolean 저장소에는 변환합니다.
검증: 표별 열 구성·문자 길이·정수·날짜·JSON·선택 코드·필수 접수값·차량/VOC 참조·1:1 연결·압력강하 계산·판정 규칙 확인 완료.
